# mirlande.nl

Website van FitCoach Mirlande Besemer. Statische site (HTML/CSS/JS), gehost via GitHub Pages.

- `index.html` – homepage
- `fitcoach-worden/` – pagina FitCoach worden
- `site.js` – knoppen, pakketkiezer, FAQ, vragenlijst (stuurt naar Google Apps Script)
- `herbalife-popup.js` – verplichte Herbalife entry-pop-up
- `img/`, `fonts/` – afbeeldingen en zelf gehoste lettertypen
- `CNAME` – koppelt het domein mirlande.nl
